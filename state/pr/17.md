## 4. Sürücü arayüzleri

`core/identity.py`
- `@dataclass DirectoryUser(provider, external_id, login, email, full_name, groups: frozenset[str], active: bool)`
- `async resolve_external_identity(session, *, email=None, upn=None, external_id=None, provider=None) -> User | None` (15'in tek çözümleyicisi; yalnız canlı + aktif; `AUTO_PROVISION_FROM_CHANNELS` kapalıyken hesap açmaz, açıkken dizinde bulunan kullanıcıyı `provision`'a verir)
- `async provision(session, du: DirectoryUser) -> User` (JIT; `email` boşsa 403 `identity_email_missing`; aynı e-postalı yerel kullanıcı → S1)
- `async apply_group_mappings(session, user, provider, groups) -> MembershipDiff` (yalnız `membership_source='idp'` satırlarına dokunur; çoklu eşleşmede en yüksek rol ve `edit` > `read`; `DEFAULT_PROJECT_FOR_NEW_USERS` → `user/read`; audit `membership_synced`)
- Entra taşması (`_claim_names` var, `groups` yok) → 400 `groups_claim_overflow`.

`core/ldap_auth.py` (`ldap3==2.9.1`)
- `class LdapDirectory(settings, server_factory=None)`: `authenticate(login, password) -> DirectoryUser` (servis hesabıyla ara → kullanıcı DN'iyle bind), `find(external_id) -> DirectoryUser | None` (sync için), `probe() -> ProbeResult(ok, elapsed_ms, code)`.
- Hatalar: `InvalidCredentials`, `ProviderUnavailable` (bağlantı/zaman aşımı/servis bind hatası → 503). ldap3 senkron: `asyncio.to_thread` + `LDAP_TIMEOUT_S` (connect + receive). Filtre `{login}` `escape_filter_chars` ile; `ldaps://` + `LDAP_CA_FILE` CA doğrulaması; `ldap://` yalnız `LDAP_ALLOW_PLAINTEXT=1`. Bağlanmadan önce `egress.check_destination(host, port)`.
- Kimlik özniteliği açık ayar `LDAP_ID_ATTR` (varsayılan `objectGUID`; OpenLDAP `entryUUID`; "auto" yok, ARCH-10). `mail`, `displayName`, `memberOf` (`LDAP_GROUP_ATTR`), AD pasifliği `userAccountControl` bit 2.
- `server_factory` testte ldap3 `MOCK_SYNC` sunucusu (ağsız, LDIF benzeri fikstür `tests/fixtures/ldap/directory.json`, sentetik).

`core/oidc_auth.py` (yeni bağımlılık yok: PyJWT + cryptography + httpx2)
- Keşif belgesi ve JWKS `SafeOutboundClient` ile (PyJWT `PyJWKClient` urllib kullanıp egress'i atlar → kullanılmaz); keşif süreç başına önbellek, JWKS `kid` yoksa bir kez yenileme.
- `start() -> (authorization_url, state)`: `state`, `nonce`, PKCE `code_verifier` Redis'te `oidc:state:<state>` TTL 600 s, `GETDEL` ile tek kullanım; tarayıcıya bağlamak için `ffcore_oidc` çerezi (HttpOnly, Lax, state özeti) → giriş CSRF'si yok.
- `callback(code, state, cookie) -> DirectoryUser`: token ucu (PKCE S256, `client_secret` varsa `client_secret_basic`), `id_token` doğrulaması: imza JWKS, `alg` yalnız RS256/RS384/RS512/PS256/ES256 (`none` ve HS* red), `iss`, `aud`, `exp`, `nonce`. `access_token`/`refresh_token` hiç saklanmaz, loglanmaz.
- `verify_id_token(token, *, nonce=None)` 15 için de tek doğrulayıcı.
- **Geri dönüş (SameSite=Strict sorunu):** IdP'den dönen gezinme siteler arası; yanıtında set edilen Strict çerez sonraki yönlendirmede gönderilmez. Çözüm: `OIDC_REDIRECT_URL` önyüz rotası `/login/callback`; sayfa `code`+`state`'i aynı origin'den `POST /auth/oidc/callback`'e yollar, oturum çerezi o yanıtta set edilir, sonra `homePath`. Preflight: `OIDC_REDIRECT_URL` origin'i `CONSOLE_ORIGINS` içinde olmalı.
- airgap: issuer host `EgressPolicy.is_internal` değilse sağlayıcı "yanlış yapılandırılmış": `/auth/providers` durumu `misconfigured`, `/auth/oidc/start` 503 `identity_provider_misconfigured`, preflight hata. Backend açılışı düşmez (süperadmin yerel kurtarma girişi sürer). llmaas: izin listesinde yoksa preflight uyarısı + çağrı `EgressDenied` → 503.
